# 📊 AWS Beginner Challenge - Day 2: Visualize Data with Amazon QuickSight

This is my solution for Day 2 of the [NextWork AWS Challenge - Analyze Data with Amazon QuickSight](https://learn.nextwork.org/projects/aws-analytics-quicksight).

## 🛠️ Steps I Followed:
1. Uploaded a dataset into an Amazon S3 bucket
2. Created an Amazon QuickSight account
3. Connected the dataset from S3 to QuickSight
4. Built visualizations using charts and graphs
5. Published an interactive dashboard with insights


## 🧠 What I Learned:
- How to import data from S3 into QuickSight
- Creating visuals like bar charts, pie charts, and line graphs
- Sharing a published dashboard with others
